# 初中英语题库与智能组卷系统

专为初中英语教师与学生设计的题库检索与试卷排版生成系统，支持七年级、八年级、九年级多题型题库检索、智能一键组卷、自建题库导入导出、在线试卷排版与一键导出 Word（.docx）试卷。

无需任何后端服务器环境，纯前端静态架构，可直接双击本地预览或一键托管至 GitHub Pages。

---

## 🌟 核心功能

1. **题库多维检索**：
   - 支持按**年级**（七年级、八年级、九年级）快捷切换。
   - 支持按**学期**（七上、七下、八上、八下、九上、九下）智能级联筛选。
   - 支持按**题型**（语法选择、完形填空、阅读理解、选词填空、书面表达）、**知识点**、**难度**及文本关键字模糊搜索。
2. **多题型题库资源**：
   - 内置共 54 组精选真题题组（七年级 10 组语法选择、八年级 15 组综合题型、九年级 29 组语法选择真题），包含完整文章材料、小题选项、答案解析与导语。
3. **智能随机组卷**：
   - 设定各题型题组数量、学期、难度与知识点，一键智能随机抽取组卷。
4. **在线试卷编排与预览**：
   - 自定义试卷标题（如“九年级英语期中复习卷”）。
   - 题组顺序上下微调、单题移除。
   - 支持「教师版（含答案详解）」与「学生版（纯试题）」一键实时切换。
5. **专业导出与打印**：
   - **Word 文档导出**：通过 `docx` 引擎在前端直接生成符合中考规范排版的 `.docx` 文件（自动排版标题、文章线框、选项制表符对齐、页码与答案解析）。
   - **一键浏览器打印**：内置打印专属媒体查询，自动隐藏操作控件，呈现标准纸质试卷布局。
6. **自建题库与持久化**：
   - 本地 `localStorage` 自动记忆已选试卷与自建题库。
   - 支持以 JSON 格式批量导入与备份导出自建题目。

## 🚀 部署到 GitHub Pages

该项目为纯前端静态页面，非常适合部署在 GitHub Pages 上：

1. **提交并推送到 GitHub 仓库**：
   ```bash
   git add .
   git commit -m "feat: split project into modular css, js, and html structure"
   git push origin main
   ```
2. **开启 GitHub Pages**：
   - 进入 GitHub 仓库页面，点击 **Settings**。
   - 在左侧菜单找到 **Pages**。
   - 在 **Build and deployment** > **Branch** 下选择 `main` 分支，目录选择 `/ (root)`。
   - 点击 **Save**。
3. **访问线上网页**：
   - 等待约 1 分钟后，GitHub Pages 会自动生成访问链接（如 `https://<用户名>.github.io/english-exam-platform/`）。

## 💻 本地运行

- **直接打开**：在访达（Finder）中直接双击 `index.html` 即可在任意现代浏览器中运行。
- **本地服务（推荐）**：
  ```bash
  # Python 3
  python3 -m http.server 8080
  # 随后在浏览器中打开 http://localhost:8080
  ```
